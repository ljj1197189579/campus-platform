# 收款码与交易使用说明

## 你第一次需要设置什么

1. 打开网站，用管理员账号登录。
2. 点击底部“我的”，进入“审核管理”。
3. 找到“服务费收款与核实”，展开“设置平台收款二维码”。
4. 上传你的微信或支付宝收款码图片，填写扫码时显示的收款人名称和付款说明，点击“保存收款方式”。

网站不会生成或替换你的收款账户。未设置二维码前，买家会看到“平台正在准备收款方式”，无法提交付款凭证。请使用你实际拥有的收款码。

## 买家怎么交易

1. 选择商品，查看实拍图片、配送方式、是否议价和卖家信用。
2. 提交购买意向，等待卖家接受。
3. 在“我的”→“我买到的”，点击“扫码付服务费”。
4. 按页面金额支付平台服务费，备注订单编号。100元的商品另付2元服务费；商品100元货款由买家和卖家另行结算，不付给平台。
5. 填写付款详情里的交易单号，上传付款截图，提交核实。截图仅自己和管理员可查看，请遮盖无关个人信息。
6. 平台核实到账后，安排线下交付。确认已收到商品并与卖家结清货款，再点击“确认收货”，之后可以评价卖家。

服务费默认按商品金额的2%计算，四舍五入到分。服务费为0元的订单无需付款凭证。本站不保证实拍图片一定真实，买家仍需核验实物。

## 你怎么核实收款

打开“审核管理”→“服务费收款与核实”→“核实处理”。

- 在你自己的微信或支付宝中查看实际收款账单，核对交易单号、金额和对应订单。
- 到账后选择“已核实到账”，填写实际账单单号及实际金额，确认保存。
- 没有到账或凭证错误时，选择“凭证未通过”，填写原因。买家可以重新提交。
- 相同到账单号不能确认到两笔订单，填写金额必须等于本单服务费。

不要仅凭截图确认付款。截图和“提交凭证”按钮都不会自动放行交易。个人收款码不能向网站提供自动到账通知，本系统采用人工核实。

## 取消和退款

已提交付款凭证或已核实到账后取消订单，会进入“等待核实退款”。

- 若实际收到款项，在原收款账户实际退回服务费后，填写退款交易单号及实际金额，再确认“已实际退款”。
- 若该凭证从未确认到账、核对后确实没有收款，可选择“核实未收到款项”并填写说明。
- 已确认收款不能再标为“未收到”。本站只记录处理结果，不会替你向微信或支付宝发起退款。

## 金额与提现为什么这样显示

“我的付款”展示已付服务费、待核实金额和待核实退款。商品货款不经过平台，卖家不会在本站得到商品余额，也没有平台提现。

你收取的服务费直接进入二维码对应的账户，可以在微信或支付宝中管理余额、提现。后台“平台收益”是人工核实后的业务统计，不代表银行或支付账户的实时余额。

## 其他页面变化

- 顶部重复的首页、商品、失物、发布菜单已移除，统一使用底部导航。
- 发布商品必须上传1至6张JPG/PNG图片，每张不超过5MB。第一张是封面，支持预览和移除。
- 商品详情和审核页面支持多图查看。
- 失物招领可搜索物品名称、描述和地点，状态统一中文显示。
- 网站前台每约5秒检查新数据；审核通过后其他用户无需手动刷新。切回浏览器窗口也会重新同步。网络中断时显示重连提示，输入中的发布表单不会被自动更新清空。
- 发布审核和收款核实是两个不同步骤。公开列表只展示通过内容审核的商品。
